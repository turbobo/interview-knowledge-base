## 使用方式

1. 按难度分层复习：初级 → 中级 → 高级
2. 每题用"三层回答法"练习：是什么 / 为什么 / 怎么用
3. 绑定项目经验：把知识点和你的项目关联
4. 模拟面试：每周 1-2 次，录音回听优化表达
